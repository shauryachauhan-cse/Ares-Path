# Route, result and photograph clarity update

The Compare routes tab now retains the interactive Jezero map. The map fits all alternatives, labels A/B/C directly on their paths, and provides visibility checkboxes and selection buttons. Blue dashed A prioritizes distance, amber solid B balances distance/slope, teal dotted C penalizes modeled slopes more strongly. A white halo identifies the selected route; overlap is real shared geometry, not an invented visual detour. Users can hide individual alternatives to inspect shared segments. An always-visible red/purple terrain legend and expandable explanation cover markers, robot symbols, highlight lines and active scientific background products. Colors indicate meaning, not operational safety rankings.

Mission Simulator now places a Calculation complete panel near Run simulation. Separate time and battery cards compare actual modeled quantities with entered budgets. The text explains that the button calculates budgets rather than starting motion. A next-step button copies the simulator's hypothetical rover configuration into Ares Experience and starts route playback. An exceeded budget is explicitly identified; the playback option remains an educational preview. Changing mission/configuration inputs marks earlier results stale and disables their launch button until recalculation.

Ares Experience densifies the visible route into ~15m samples before perspective projection, rather than drawing only sparse endpoints that can be clipped behind the camera. A dark-outlined yellow route and teal diamond checkpoints show the path ahead. The minimap is larger and uses the same yellow path. No route coordinates are changed by this rendering.

A separate Real Perseverance photos view displays the existing genuine NASA Mastcam-Z panorama, both as a full photograph and a horizontally wrapping look-around view. The interactive view now includes the photographed horizon by default. Source: PIA24264, acquired February21,2021 and published February24,2021, stitched from142 images; NASA/JPL-Caltech/MSSS/ASU. https://science.nasa.gov/photojournal/mastcam-zs-first-360-degree-panorama/

This is photographed context at one location. It is not an exact 3D photographic reconstruction of an arbitrary route, and no route is falsely projected onto the photograph without camera geometry or per-pixel geographic registration. The DEM drive view remains a labeled educational simulation. The existing historical availability controls are retained.

Validation: all23 existing automated tests pass and production build succeeds. Browser checks verified three simultaneous route alternatives, hiding B to reveal A/C, fit and selection controls, successful time/battery result cards, stale-result launch disabled after input changes, failed time budget explanation, launch/copy from results into rover playback, visible yellow path/diamonds, real-photo overview, and look-around panorama with horizon. Browser extension log errors were unrelated to application code; no application JavaScript exception was observed during these checks. A dedicated mobile-device run was not performed.
