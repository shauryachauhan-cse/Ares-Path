# Ares Path: reproducible Jezero demonstration

Purpose: connect a specific science task to visible terrain and resource tradeoffs. This is a student planning prototype, not an operational EVA tool.

## 30-second demonstration outline

- 0–5 s: Mission Control → Load mission & compare routes. Explain the fictional base and sourced fan-front coordinate.
- 5–14 s: Compare blue A with amber B. B adds about 0.65 km return distance, reduces the modeled maximum slope from 5.4° to 2.9°, and costs about 24 extra minutes and 36 Wh.
- 14–22 s: Check resources → Run simulation. Explain 300-minute allocation, rover battery reserve and unmeasured conditions.
- 22–30 s: Next: drive this route. Show the yellow path and rover moving; mention that real photographs are a separate context view.

This is a recording script, not a claim that a demo video has been recorded or a project has been submitted. Verify the current official submission requirements yourself before submitting.

## Science and coordinate provenance

Objective: a hypothetical visual survey of layering and sediment textures near the Jezero western fan front, not sample retrieval. The destination [77.41359752 E, 18.45369687 N] is the USGS tutorial coordinate described as near Three Forks and the front of the western fan:
https://stac.astrogeology.usgs.gov/docs/tutorials/mosaic_json_analysis/

NASA's sample depot context:
https://science.nasa.gov/resource/perseverances-three-forks-sample-depot-map/

The point is not an exact sample-tube location or a verified accessible observation station. Base [77.435,18.421], task duration, robot specifications and all operational choices are scenario assumptions. Endpoints snap about 22 and 29 m to the planning grid.

## Reproduction

From the source root:

```sh
node scripts/benchmark.mjs
npm run build
npm test
```

`public/demo-mission.js` contains shared fixed inputs; `public/benchmark.json` contains numeric outputs and SHA-256 hashes for the DEM and mapped-bedform mask. The benchmark is generated by the actual route engine, estimate model and rover energy model. Tests verify dataset hashes, outputs and distance consistency. Local distance calculations now use the same 3,396.19 km cartographic sphere as the local terrain grid; estimates for older saved routes may change about 0.2% from the earlier mean-radius convention.

B is recommended by the configured shared distance/slope score. C has a larger terrain penalty and may share B's maximum slope while following different terrain. There is no independent accuracy evaluation, user-study result, calibrated human risk metric or validated rover specification. The fixed example's paths are unchanged by toggling bedform avoidance; do not claim a dune-avoidance benefit for this example. Other automated routing cases verify mapped deposits are actually excluded.

## Data use

Optical CTX imagery, topographic CTX DEM, THEMIS thermal context, and CRISM spectral context appear in the map. USGS SIM 3464 mapped Aeb deposits support an optional exclusion policy. Historical MEDA (Jezero) and RAD (Gale) observations are context only; they do not establish current Jezero conditions.
